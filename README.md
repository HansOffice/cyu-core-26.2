# CyuCore 26.2 原生服务端核心 (Go Engine)

基于纯 Go 标准库实现的 Minecraft 26.2 原生游戏服务端。零 Java 依赖，真实支持客户端握手、登录、进入世界、加载地形区块、移动同步、多人交互与游戏内指令。

## 特性亮点

- **全自研 0 外部依赖**：不依赖 JVM，100% 采用 Go 标准库，编译产物仅 ~3.5MB，内存占用仅百 KB 级
- **原生 26.2 协议全链路支持**：
  - 协议版本号：`776`（对应 Minecraft 26.2）
  - 完整实现现代状态机：`Handshake` ➔ `Login` ➔ `Configuration` ➔ `Play`
  - 完整对接 26.1+ 流体分离架构（Chunk Section `fluid_count` 规范与现代 Heightmaps）
- **真实可进入的游戏世界**：
  - 客户端不再弹出断开拦截，直接完成地形加载进入世界
  - 出生点自动生成安全石质浮空悬空平台（16x16 踩踏区域），杜绝虚空跌落
  - 默认开启创造飞行模式（可在 `config.yml` 调整为生存模式）
  - 真实 Tab 列表玩家信息同步（`PlayerInfoUpdate`）
- **实时多人与交互**：
  - 多人同屏：实时广播 `AddEntity` 与 `EntityPositionSync`，玩家之间可见彼此走动与挥手动作
  - 方块破坏与放置：支持右键放置石砖方块、左键瞬间破坏方块并实时广播至全服
  - 虚空跌落保护：不慎掉出平台自动安全拉回出生点
  - 动态昼夜时间：世界时间自动流转，支持 `/time` 实时调控
- **游戏内原生指令系统**：
  - 注册服务端命令树（`CommandsPacket` 0x11），支持客户端 Tab 键补全
  - `/gamemode <0-3>` 切换生存/创造/冒险/旁观
  - `/tp <玩家名 | x y z>` 空间瞬移传送
  - `/spawn` 返回出生点中心平台
  - `/time <set|add> <值>` 切换昼夜时间
  - `/say <消息>` 全服广播
  - `/ping` 测试网络延迟
- **双端单文件开箱即用**：
  - Linux: `cyu-server-26.2`
  - Windows: `cyu-server-26.2.exe`

## 运行指南

### Linux
```bash
chmod +x cyu-server-26.2
./cyu-server-26.2
```

### Windows
直接双击 `cyu-server-26.2.exe` 或在 CMD / PowerShell 运行：
```cmd
cyu-server-26.2.exe
```

首次运行自动生成 `config.yml`，默认监听 `25577` 端口。

## 指令一览

### 控制台指令

| 指令 | 说明 |
|---|---|
| `help` | 查看控制台命令帮助 |
| `list` | 查看当前真实在线玩家与坐标 |
| `say <message>` | 向全服在线玩家广播游戏内聊天栏消息 |
| `kick <player> [reason]` | 踢出指定在线玩家 |
| `tps` | 查看核心实时 TPS 与微秒耗时 |
| `status` | 查看运行时间、在线人数与内存占用统计 |
| `stop` | 踢出全服玩家并安全关闭服务端 |

### 游戏内玩家指令

| 指令 | 说明 |
|---|---|
| `/help` | 查看游戏内指令指南 |
| `/gamemode <0-3>` | 切换游戏模式（生存/创造/冒险/旁观） |
| `/tp <玩家名 \| x y z>` | 传送至指定玩家或坐标 |
| `/spawn` | 安全传送回出生点平台 |
| `/time <set\|add> <值>` | 调整世界时间（支持 day/night/数值） |
| `/say <消息>` | 发送全服广播 |
| `/ping` | 测试当前核心延迟 |
